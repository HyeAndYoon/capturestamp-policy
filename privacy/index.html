개인정보처리방침

CaptureStamp는 활동 인증에 필요한 정보를 가능한 한 사용자 기기 안에서 처리합니다.

참가자 정보

참가자가 입력한 답변, 선택한 사진, 촬영 주소 및 제출 초안은 앱 서버로 업로드하지 않습니다. 사용자가 검토한 뒤 선택한 외부 메일 앱으로 직접 전달합니다. 메일 전송과 보관에는 해당 메일 서비스의 정책이 적용됩니다.

관리자 계정과 양식

관리자 기능에 로그인하면 Google이 발급한 ID 토큰을 서버에서 검증합니다. 서버는 확인된 Google 이메일을 관리자 식별, 본인이 만든 양식의 소유권 확인, 변경 이력 기록에 사용합니다. Google 비밀번호와 메일 내용은 수집하지 않습니다.

서버에는 관리자가 작성·배포한 공개 양식 정의, 수신 이메일 주소, 개정 번호 및 관리 변경 이력이 저장됩니다. 참가자의 답변과 사진은 저장하지 않습니다.

관리자 이메일은 계정과 프로젝트의 삭제 예정 안내를 발송하는 데 사용합니다. 발송 제공자가 요청을 접수한 이후의 전달, 반송, 스팸 처리 및 열람 상태는 수집하거나 삭제 판단에 사용하지 않습니다.

위치와 기기 권한

주소 표시를 켠 경우에만 앱 사용 중 위치 권한을 요청해 현재 위치를 주소로 변환합니다. 백그라운드 위치 추적은 하지 않습니다. 카메라, 사진 및 저장소 권한은 촬영·사진 선택·저장을 위해서만 사용합니다.

보관과 삭제

참가자 제출 초안과 임시 복사본은 기기에 보관되며 앱의 보관 정책 또는 사용자의 삭제 동작에 따라 제거됩니다. 로그아웃하면 해당 기기의 관리자 로그인 세션이 종료됩니다.

관리자는 앱의 관리자 화면에서 계정 삭제를 요청하거나 웹 계정 삭제 요청 안내를 이용할 수 있습니다. 요청 즉시 계정과 모든 연결 양식이 비활성화되며, 30일의 복구기간이 지나면 양식과 계정 식별정보를 영구 삭제합니다.

프로젝트나 계정을 영구 삭제할 때 관리자 변경 이력에서 이메일, 수신처, 참여코드와 연결 식별자를 제거합니다. 식별정보가 제거된 작업 종류와 시각은 보안 및 장애 조사 목적으로 최대 365일 보관한 뒤 삭제합니다. 서비스 백업과 외부 메일 제공자 로그에는 각 서비스의 제한된 복구·보관 기간이 별도로 적용될 수 있습니다.

외부 서비스

관리자 로그인에는 Google Sign-In을, 공개 양식과 관리자 설정 제공에는 Cloudflare 기반 서비스를 사용합니다. 사용자가 선택한 외부 메일 앱에는 해당 서비스의 개인정보처리방침이 적용됩니다.
